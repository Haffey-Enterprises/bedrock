# Security policy

Report suspected Bedrock package vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Haffey-Enterprises/bedrock/security/advisories/new).
On GitHub, open Security → Advisories → Report a vulnerability. Do not place
secrets, active credentials, private consumer content, or exploit details in a
public issue.

Include the manifest identity, installation surface, reproduction, impact, and
whether active exploitation is suspected. The complete installed-package
security, support, and deprecation contract is in
[`plugins/bedrock/governance/POLICIES.md`](plugins/bedrock/governance/POLICIES.md),
and the package threat model is in
[`plugins/bedrock/governance/THREAT-MODEL.md`](plugins/bedrock/governance/THREAT-MODEL.md).
