# agent-core 0.2.1

Mandatory shared substrate for every LLM-calling agent in the fleet.

See [USAGE.md](USAGE.md) and [DESIGN-NOTES.md](DESIGN-NOTES.md).

The accepted source was exercised by one bounded direct-Anthropic specialist trial.
That historical result is not proof of a new build or other providers. Repository
integration evidence identifies the installed package tested for each candidate.

Bedrock bundles the built wheel with agent-builder. Install and pin it through that
skill into the consuming project environment. Source-only development installation:
`python -m pip install -e packages/agent-core`. License: Bedrock MIT.
